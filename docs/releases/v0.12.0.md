# v0.12.0

**Release Date:** 2026-11-16

Adds **re-takes**: after listening to a recording, synthesize only the slides that
sounded wrong again. Every other slide reuses its cached clip, so a correction costs only
the re-taken slides' characters.

## Highlights

- **`--retake`:** `vac html video --lessons … --retake <slide IDs>` synthesizes the named
  slides' narration again in every `--lang` and rebuilds each lesson's audio from the new
  clips and the other slides' cached clips

## Added

- `vac html video --retake` — slide IDs (`data-id`) whose cached narration clips are
  deleted and synthesized again; each must be in a lesson that `--lessons` selects, and an
  unknown slide, or one in a lesson not being recorded, is an error. It works with or
  without `--audio-only`
- `tts.SegmentTTSGenerator.RemoveClips` — deletes the cached clips of chosen voiceovers and
  the segment's audio metadata, so only they are synthesized again

## Usage

```bash
# Re-record two slides of the tractors lesson, reusing every other clip
vac html video --input deck/index.html --lessons tractors --audio-only \
  --retake tractors,tractors-engines
```

AcademyOS's Review tab lists a lesson's slides marked for a re-take and shows this
command, ready to copy.
