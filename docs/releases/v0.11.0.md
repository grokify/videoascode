# v0.11.0

**Release Date:** 2026-11-13

Adds **transcript review**, so a deck's narration is read and approved slide by slide
before any of it is sent to a TTS provider, and **recordings for course platforms**: one
`vac html video --lessons` run now produces each lesson's video, its YouTube chapters, and
the lesson's audio with each slide's start time, which a course platform such as AcademyOS
plays with the slides.

## Highlights

- **`vac html review`:** a page with the deck on one side and its transcript on the other,
  with checks for text TTS reads badly, a browser-voice preview, and approvals tied to the
  exact text approved
- **`--require-review`:** `vac html video` refuses to record until every slide being
  recorded is approved in every language
- **Recordings for course platforms:** `vac html video --lessons … --recordings` writes each
  lesson's MP3, WebVTT captions, and slide timings into the deck's `recordings/` in the
  course-spec format; `--audio-only` writes them without recording video
- **YouTube chapters:** each lesson video gets a `.chapters.txt` with a chapter per slide,
  ready for the video's description

## Added

- `vac html review` — serves a review page for one deck or many (`--input` and arguments),
  on `--port` (default 8765), opened with `--open`:

    - the narration sentence by sentence, the text TTS receives after pronunciations, and
      words and estimated seconds per slide
    - checks: missing narration or translation, symbols, addresses, unknown directives,
      long sentences, numbers, acronyms without a pronunciation, long and silent slides
    - a browser-voice preview of the current slide or from it onward, highlighting each
      word
    - approve or request changes per slide and language, saved to `voiceover/review.json`
      (`--review-file`, `--reviewer`); a decision goes stale when the text it was made on
      changes
    - `--lang` to review some languages, `--summary` to print progress, and `--export` to
      write a read-only snapshot page
- `vac html video --require-review` — stop before any TTS call unless every slide being
  recorded is approved for every `--lang`
- `pkg/review` — the review model, checks, decisions file, and page server
- `vac html video --lessons … --recordings` — also write each recorded lesson's audio,
  captions, and slide timings into the deck's `recordings/`
- `vac html video --lessons … --audio-only` — write the recordings without recording video;
  with it, `--lessons changed` selects lessons whose recording is missing or out of date for
  the narration
- `pkg/recording` — slide timings from clip lengths and pauses, WebVTT captions with a cue
  per sentence, YouTube chapters, and writing a lesson into `recordings/recordings.json`
  with course-spec narration fingerprints
- YouTube chapters beside each lesson video, `NN-<title>.chapters.txt`: a chapter per slide
  of at least ten seconds, the first at `0:00`, written when a lesson has three or more;
  `lessons.json` lists them under `chapters`
- `make vendor-speech` — copies the browser speech library used by the review page

## Changed

- `vac browser video` and `vac html video` share one TTS provider and voice setup, so
  recordings reuse the clips a video run synthesized

## Usage

```bash
# Read and approve each slide's narration before any TTS call
vac html review --input deck/index.html --open

# Record only once every slide being recorded is approved
vac html video --input deck/index.html --lessons all --require-review

# Videos, chapters, and course recordings in one run
vac html video --input deck/index.html --lessons changed --recordings

# Course recordings only, without video
vac html video --input deck/index.html --lessons all --audio-only
```

A lesson's recording, beside the deck:

```text
deck/
  index.html
  recordings/
    recordings.json
    en-US/tractors.mp3
    en-US/tractors.vtt
```
