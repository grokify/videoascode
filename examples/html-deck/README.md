# HTML Deck Example

A four-slide native HTML deck narrated from the deck itself. It shows both narration
sources vac reads — a `data-vo` attribute and a reveal.js-style `<aside class="notes">` —
plus a `[PAUSE:ms]` directive, a pronunciation file, and two lessons marked with
`data-lesson`.

## Files

| File | What it is |
| --- | --- |
| `index.html` | The deck: a fixed 1280×720 stage, ArrowRight to advance, `?capture=1` hides the page number, `#<slide id>` opens at a slide |
| `pronunciations.json` | How TTS should say `vac` and `data-vo`; subtitles keep the written form |
| `voiceover/transcript.json` | Generated by `vac html init`: the narration in transcript format |
| `deck.video.json` | Generated by `vac html init`: a `vac browser video` config, one step per slide |

## Record It

From the repository root:

```bash
vac html video \
  --input examples/html-deck/index.html \
  --pronunciations examples/html-deck/pronunciations.json \
  --output examples/html-deck/output.mp4 \
  --provider deepgram --subtitles
```

vac serves `examples/html-deck/` on a loopback port, opens `index.html?capture=1`, and
presses ArrowRight once per slide. Each slide stays on screen for its own narration, plus
600 ms after the second slide.

## Record It as Lessons

```bash
vac html lessons --input examples/html-deck/index.html
vac html video \
  --input examples/html-deck/index.html \
  --pronunciations examples/html-deck/pronunciations.json \
  --lessons all
```

Slides 2 and 4 carry `data-lesson`, so the deck has two lessons; the title slide joins
the first. vac opens `index.html?capture=1#record` to record the second lesson. Videos
and `lessons.json` go to `examples/html-deck/lessons/`; after an edit,
`--lessons changed` re-records only the affected lesson. See the
[Lessons and Courses guide](../../docs/guides/lessons.md).

## Regenerate the Transcript and Config

After editing narration in `index.html`:

```bash
vac html init \
  --input examples/html-deck/index.html \
  --pronunciations examples/html-deck/pronunciations.json
```

Add a translation by giving each slide in `voiceover/transcript.json` another language
(for example `"fr-FR": {"segments": [{"text": "…"}]}`). Re-running `vac html init` keeps
it, and once it covers every slide it is added to `deck.video.json`. Record it with
`--lang en-US,fr-FR`.

To record from the generated config instead of `vac html video`, serve the folder
yourself:

```bash
cd examples/html-deck && python3 -m http.server 8000 &
vac browser video --config examples/html-deck/deck.video.json --output output.mp4
```

See the [HTML Slide Decks guide](../../docs/guides/html-decks.md) for the conventions.
